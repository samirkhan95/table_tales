# Contributing & Showcase Overview

Thank you for your interest in **TableTales**!

This repository is maintained as a **Showcase & Portfolio Project** to demonstrate clean Flutter architecture, custom UI components, local persistence with SQLite, state management with Provider, and data visualization.

---

## 🛠️ Testing the App

If you are a reviewer or recruiter looking to test the application live on an Android device, please download the compiled release binary from the [Releases](https://github.com/samirkhan95/table_tales/releases) section.

---

## 🐞 Issues & Feedback

If you find any bugs or have suggestions regarding the UI, UX, or code architecture, feel free to open an issue or submit a pull request!
